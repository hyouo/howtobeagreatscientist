# How to Be a Great Scientist

一份关于**如何选问题、检验证据、保持科学诚信、组织合作、写清楚论文，以及理解科学职业**的中文阅读与实践指南。

这里把优秀科研理解为：提出值得回答的问题，可靠地积累证据，允许结论被修正，并让别人能够理解、检验和继续这项工作。每篇导读包含书目信息、核心观点、实践问题、适用边界和原文入口。

目前收录 **12 篇经典文本、6 篇现代研究实践文本**，并提供可用于个人项目或读书会的练习模板。中文标题为参考译名，导读和练习均不替代原文。

## 系统阅读路线

[四周阅读路线](articles/classic-essays.md#reading-plan)覆盖全部经典条目，每周配一项产出。时间有限时可按下列主题跳读：

1. **为什么做研究**：Cajal、Weber、Hamming
2. **怎样提出并检验解释**：Bernard、Chamberlin、Platt
3. **怎样不欺骗自己**：Feynman
4. **怎样选择值得做的问题**：Alon、Schwartz
5. **怎样把研究写清楚**：Gopen & Swan、Whitesides
6. **科学与社会如何相互支持**：Bush

完成经典阅读后，可按实际项目需要选读现代篇：做数据分析时读 ASA 与 Nosek，整理研究材料时读 Wilson 与 FAIR，开始合作时读团队科学指南。每周投入和任务规模可按学科调整。

## 收录原则

1. 优先收录由科学家、科学史家或研究方法论作者写成，并经长期检验仍有启发的文本。
2. 每个条目尽量链接期刊、出版社、大学档案、政府机构或 Project Gutenberg 等可靠来源。
3. 对仍受版权保护的作品，只提供原创中文导读、书目信息和合法原文入口，不在仓库中复制全文。
4. 对公版或开放许可作品，加入全文前也要记录版本、来源和许可状态；版权状态可能因司法辖区而异。
5. 导读应区分作者原意、整理者概括和当代批评，避免把名言式摘录当成完整论证。

## 如何判断自己有进步

- 能说清一个项目要改变哪一项已有认识，以及什么证据会让自己改变判断。
- 能指出研究设计排除了哪些解释、仍留下哪些不确定性。
- 合作者能根据记录理解分析过程，并在允许的条件下重现关键结果。
- 能明确报告失败、局限和实际贡献，也能在证据不足时调整或终止项目。

这些是学习时的自查问题，不能直接用作跨学科排名或人员考核。理论、田野、质性、实验和计算研究需要不同的证据与评价方式。

研究生、青年教师、工程研究人员，以及任何希望系统训练科研判断力的人。

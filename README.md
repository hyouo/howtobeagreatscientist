# How to Be a Great Scientist

一份关于**如何做研究、如何选问题、如何保持科学诚信、如何写清楚论文，以及如何理解科学职业**的经典文章导读。

本仓库不追求堆积下载文件，而是提供一条可读、可验证、尊重版权的阅读路径：每篇条目包含作者、年代、核心观点、实践问题和原文入口。

## 开始阅读

- [经典文章导读：从研究方法到科学职业](articles/classic-essays.md)
- [如何贡献新的文章](CONTRIBUTING.md)

建议阅读顺序：

1. **为什么做研究**：Cajal、Weber、Hamming
2. **怎样提出并检验解释**：Bernard、Chamberlin、Platt
3. **怎样不欺骗自己**：Feynman
4. **怎样选择值得做的问题**：Alon、Schwartz
5. **怎样把研究写清楚**：Gopen & Swan、Whitesides
6. **科学与社会如何相互支持**：Bush

## 收录原则

1. 优先收录由科学家、科学史家或研究方法论作者写成，并经长期检验仍有启发的文本。
2. 每个条目尽量链接期刊、出版社、大学档案、政府机构或 Project Gutenberg 等可靠来源。
3. 对仍受版权保护的作品，只提供原创中文导读、书目信息和合法原文入口，不在仓库中复制全文。
4. 对公版或开放许可作品，加入全文前也要记录版本、来源和许可状态；版权状态可能因司法辖区而异。
5. 导读应区分作者原意、整理者概括和当代批评，避免把名言式摘录当成完整论证。

## 适合谁

研究生、青年教师、工程研究人员，以及任何希望系统训练科研判断力的人。
